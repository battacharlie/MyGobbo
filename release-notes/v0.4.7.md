## English – what's new in 0.4.7

- **NDI output**: File → Output → "Send the output over NDI". The output appears on the network as the "IGOR - ABit/s" source, at the output frame rate (max 25 fps); the menu shows how many receivers are connected.
- **Light / full mode**: the button at the top right of the inputs column switches to light mode, which turns off scenes and studio mode to save resources. The scene on air becomes a simple list of inputs in the same positions, without interrupting the output; the other scenes are set aside with their sources closed and come back in full mode. Studio mode is now in the View menu (full mode only).
- 0.4.6: free and resizable detail panels, panels in separate windows, IGOR logo colours, File → Output.

## Italiano – novità della 0.4.7

- **Uscita in NDI**: File → Uscita → "Invia l'uscita in NDI". In rete l'uscita compare come sorgente "IGOR - ABit/s", ai fotogrammi al secondo dell'uscita (al massimo 25); il menu mostra quanti ricevitori sono collegati.
- **Modalità light / full**: il pulsante in alto nella colonna degli input passa alla modalità light, che spegne scene e modalità studio per consumare meno risorse. La scena in onda diventa un semplice elenco di input nelle stesse posizioni, senza interrompere l'uscita; le altre scene vengono messe da parte con le sorgenti chiuse e tornano in modalità full. La modalità studio ora si trova nel menu Visualizza (solo in modalità full).
- 0.4.6: schede dei dettagli libere e ridimensionabili, schede in finestre separate, colori del logo IGOR, File → Uscita.
