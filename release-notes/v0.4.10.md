## English – what's new in 0.4.10

- **IGOR now runs on Mac too**, with the same features as on Windows (NDI included): one download for Macs with an Apple processor (M1, M2, M3…) and one for Macs with an Intel processor.
- On Mac the full-screen output stays on the chosen monitor without opening a new desktop.

**First start on Mac:** the app is not signed with an Apple certificate, so macOS blocks it the first time. Open **System Settings → Privacy & Security**, scroll down and press **Open Anyway** (on older macOS versions: right-click the app → **Open**). If macOS says the app "is damaged", open Terminal and type `xattr -cr "/Applications/IGOR - ABits.app"`. macOS also asks for **Camera** access (capture devices) and **Screen Recording** access (colour picker; restart the app after allowing it).

## Italiano – novità della 0.4.10

- **IGOR ora funziona anche su Mac**, con le stesse funzioni di Windows (NDI compreso): un file per i Mac con processore Apple (M1, M2, M3…) e uno per i Mac con processore Intel.
- Sul Mac l'uscita a tutto schermo resta ferma sul monitor scelto, senza aprire una nuova scrivania.

**Primo avvio su Mac:** l'app non è firmata con un certificato Apple, quindi la prima volta macOS la blocca. Apri **Impostazioni di Sistema → Privacy e sicurezza**, scorri in basso e premi **Apri comunque** (sulle versioni più vecchie di macOS: clic destro sull'app → **Apri**). Se macOS dice che l'app "è danneggiata", apri il Terminale e scrivi `xattr -cr "/Applications/IGOR - ABits.app"`. macOS chiede anche il permesso per la **Fotocamera** (periferiche di acquisizione) e per la **Registrazione schermo** (contagocce dei colori; dopo averlo concesso riavvia l'app).

## Download / Scarica

- `IGOR-ABits-Setup-0.4.10.exe`: Windows installer / installazione Windows.
- `IGOR-ABits-0.4.10-portable.exe`: Windows, runs without installing / si avvia senza installare.
- `IGOR-ABits-0.4.10-mac-arm64.dmg`: Mac with Apple processor / Mac con processore Apple.
- `IGOR-ABits-0.4.10-mac-x64.dmg`: Mac with Intel processor / Mac con processore Intel.
- `.zip` files: the same Mac app without the disk image / la stessa app per Mac senza immagine disco.
