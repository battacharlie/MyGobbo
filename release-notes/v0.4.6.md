## English – what's new in 0.4.6

- Input details panels are free: move them anywhere and resize width and height of each one independently (with a minimum size).
- ⧉ opens a single panel, or all the input details, in a separate window.
- IGOR logo colours: blue **+** (now centred), blue CUT, grey FADE; red only for on air and Delete, green for preview.
- Studio mode no longer shows the "foreground to background" heading.
- With instructions off, the "How to use it" panel disappears.
- The Output menu is now under **File → Output**.

## Italiano – novità della 0.4.6

- Le schede dei dettagli input sono libere: si spostano dove si vuole e ognuna si allarga e si alza da sola (con una misura minima).
- ⧉ apre una singola scheda, o tutti i dettagli input, in una finestra separata.
- Colori del logo IGOR: **+** blu (ora centrato), CUT blu, FADE grigio; rosso solo per in onda ed Elimina, verde per l'anteprima.
- In modalità studio non c'è più l'intestazione "dal primo piano allo sfondo".
- Togliendo le istruzioni scompare anche la scheda "Come si usa".
- Il menu Uscita ora è in **File → Uscita**.
