### 这是什么
IGOR 是一款适用于 Windows 和 Mac 的小型视频导播软件。**控制窗口**位于主显示器上，**输出**在第二台显示器上全屏显示（只有一台显示器时以窗口形式出现）。输出画面可以组合 NDI 信号、摄像头和采集卡、视频和图片、计时器、文字横幅以及提词器。输出按其所在显示器的帧率运行（Auto），也可以在底部栏中降低帧率以节省资源。

### 控制窗口概览
- **顶部菜单**
  - *文件*：导入和导出配置，设置输出背景颜色。
  - *视图*：轻量模式、导播模式、显示或隐藏说明、重置窗口布局、本手册。
- **底部栏**
  - 左侧（蓝色）：**重置面板窗口** 将所有详情面板恢复到初始位置；**分离详情窗口** 在独立窗口中打开输入详情（同一个按钮变为 *合并详情窗口*，可将其放回控制窗口）。
  - 右侧（灰色）图标依次为：**NDI**（绿色 = 输出以 “IGOR - ABit/s” 信号源发送到网络，红色 = 关闭；鼠标悬停可查看名称和已连接的接收端）、**显示器**（显示/隐藏输出）、选择**显示器**和**帧率**、**导入**和**导出**配置（`.igor` 文件）、**语言**（意大利语、英语、西班牙语、法语、中文、阿拉伯语）、**MIDI 控制器**以及 **Companion / Stream Deck**。
  - 显示器编号规则：主显示器为 1 号，其余显示器从左到右依次编号。
- **预览**（上方）：拖动元素可移动位置，拖动四角可调整大小（按住 Shift 保持比例）。在视频和图片上，橙色手柄用于裁剪。
- **输入列**（右侧）：蓝色 **+** 按钮用于添加输入（NDI、采集设备、媒体、计时器、文字横幅、TelePrompt）。要创建场景，请点击底部的 **添加场景**，再点击要放入场景的输入（可选多个，不选则创建空场景），然后点击 **添加**；**LIGHT** 按钮切换到轻量模式，之后变为 **STUDIO**，用于返回完整模式（见下文）。
  - 列表从前景到背景排列；拖动可调整顺序，或把输入放入某个场景（松开时按住 Ctrl = 同时放入该场景）。
  - 列表上方的 **全部显示** 可让所有输入重新可见。
  - 每一行：👁 显示/隐藏，↺ 重置该输入的尺寸和设置，红色垃圾桶用于删除。
  - Ctrl + 点击或 Shift + 点击可选择多行；右键单击会出现针对所有选中行的 *删除* 和 *重置输入*。
- **输入详情**（下方）：所选输入的设置，分为多个面板。
  - 拖动标题可移动面板，拖动其右边缘和下边缘可加宽或加高，各面板互不影响。
  - 点击标题（或 ▾ 标签）可将面板折叠成一条栏。
  - ⧉ 按钮可在独立窗口中打开该面板，窗口可放在任意位置（包括另一台显示器）；*移回控制窗口* 可将其放回原处。

### 颜色
- 红色：播出中，以及 *删除* 按钮。
- 绿色：预览。
- IGOR 蓝和灰：操作按钮（CUT 为蓝色，FADE 为灰色）。

### 场景与导播模式
一个场景包含多个输入；同一时间只有一个场景在播出。不属于任何场景的输入始终可见。**导播模式**会显示两个画面：左侧为**预览**（绿色），右侧为**播出**中的画面（红色）；中间是 **CUT**（硬切）和 **FADE**（叠化），并可选择叠化时长。

### 轻量模式与完整模式
- **完整模式**：全部功能，包括场景和导播模式。
- **轻量模式**（LIGHT 按钮）：适用于性能较弱的电脑。场景和导播模式会关闭；正在播出的场景中的输入变为一个简单列表，位置保持不变，输出不会中断。其他场景被暂时搁置，其信号源（摄像头、NDI、视频）会被关闭。轻量模式下只能添加计时器、TelePrompt、图片、一个采集设备和一路 NDI 信号。
- 点击 STUDIO 按钮返回完整模式：场景恢复，之前的场景带着期间所做的修改重新播出。在轻量模式下添加的输入保持在场景之外。

### 元素
- **计时器**：倒计时或秒表，三种颜色（开始、接近结束、超时），时间到时边框闪烁，停止时显示时钟，计时结束提示音（铃声或音频文件，可选择音频输出，可重复）。空格键 = 开始/暂停。
- **文字横幅**：一条文字带，长度超过屏幕时会滚动。
- **TelePrompt**：文字以设定的速度向上滚动；可直接输入、粘贴或导入（.docx、.rtf、.txt、.html）；字号以磅为单位；镜像和阅读线使用图标按钮；离开或进入播出时自动暂停和播放。
- **NDI**、**采集设备**、**媒体**（视频和图片）：适配 / 填充 / 拉伸，按 % 或像素裁剪；视频还有：可拖动的时间线，可设置入点和出点，循环播放，播出时播放，不在播出时暂停并倒回，“跟随”音频（仅在播出时有声音）。
- **在输入上单击右键**：复制、剪切、粘贴，复制和粘贴属性（仅外观，限同类型输入之间）。

### 远程控制
- **MIDI**：选择一个命令，按下 *学习*，然后触碰控制器上的按键。
- **Companion**：启用 *接受 HTTP 命令*，并使用类似 `http://127.0.0.1:8765/api/cut` 的地址（*Generic HTTP* 模块）。完整指南（英语和意大利语）：[COMPANION.md](COMPANION.md)。

### 小贴士
- *视图 → 重置窗口布局* 可将面板和区域恢复到初始状态。
- 配置会自动保存；如需迁移到另一台电脑，请使用底部栏中的 *导出* 图标。
